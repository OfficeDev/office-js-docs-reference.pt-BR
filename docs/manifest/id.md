# <a name="id-element"></a>Elemento Id

Especifica a ID exclusiva de seu Suplemento do Office como um GUID.

**Tipo de suplemento:** Conteúdo, Painel de tarefas, Email

## <a name="syntax"></a>Sintaxe

```XML
<Id>string</Id>
```
