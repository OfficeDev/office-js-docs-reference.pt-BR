Para exigir o conjunto de API de identidade 1.3 em seu código de suplemento do Outlook, verifique se ele é suportado chamando `isSetSupported('IdentityAPI', '1.3')`. Não é permitido declará-lo no manifesto do suplemento do Outlook. Você também pode determinar se a API tem suporte, verificando se ela não é `undefined`. Para mais detalhes, confira [Usar APIs de conjuntos de requisitos posteriores](/javascript/api/requirement-sets/outlook/outlook-api-requirement-sets#using-apis-from-later-requirement-sets).
